# Mehdi Hassan — Data Analyst & BI Developer

A responsive, static portfolio website. No build step or package installation is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish on GitHub Pages

Push the contents of this folder to the repository's publishing branch and enable GitHub Pages for the repository. Keep `index.html`, `css/portfolio.css`, and the referenced PNG images at their existing relative paths.

## Contact details

The email address, phone number, LinkedIn profile, and Fiverr portfolio links are in `index.html`.
